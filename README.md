# AegisPay Financial Crime Intelligence

> **This repository has moved.** The full project — architecture, pipelines,

AegisPay is a production-oriented Databricks reference platform for detecting
payment fraud, account takeover, money-laundering patterns and coordinated
criminal networks. It converts payment, identity, authentication, device and
access activity into governed, explainable, investigation-ready decisions
using Lakeflow Declarative Pipelines (Bronze / Silver / Gold), Unity Catalog,
MLflow and AI/BI dashboards. All records and labels are synthetic.
